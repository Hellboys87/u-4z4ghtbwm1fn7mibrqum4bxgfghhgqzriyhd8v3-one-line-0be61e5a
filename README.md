My entry for make.fun's "One Line, One Laugh" bounty: a tiny Node program that writes a single one-liner — a goldfish wins custody of its owner in court, because even a three-second memory beats someone who forgets dinner every day.

## Run it

```sh
node main.ts
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset) and throws instead if the line were ever empty or longer than the competition's 140-character limit.
